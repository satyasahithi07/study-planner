# 📚 Study Planner

A web-based study planning application designed to help students
organize, schedule, and manage their learning activities effectively.

## 🎯 Project Overview

Study Planner helps students create a structured study routine,
manage their learning activities, and stay organized with their
academic goals.

The project was developed to practice web development concepts
and build a practical application focused on student productivity.

## ✨ Features

- Create and organize study activities
- Plan study schedules
- Manage learning tasks
- Simple and user-friendly interface
- Helps students maintain an organized study routine

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
